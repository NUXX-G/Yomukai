## Yomukai 2.8.0 — Lo que pediste tras probar la 2.7.0

### Cambios
- **Doblaje: ya no es una categoría.** Fuera la sección «Doblajes» y el selector por doblaje: el anime se abre en
  japonés con subtítulos en tu idioma y, si un servidor es castellano o latino, lo dice con una etiqueta (CAST / LAT).
- **Leviathan (y otros de ManhwaWeb) ya abren**: la web movió las imágenes de cada capítulo a su «versión» y daba
  error 404; ahora se lee la versión.
- **Manga y Manhwa/manhua ya no salen casi vacíos**: cada fila se rellena con obras de tus fuentes (populares, por
  género, en publicación), así un manhwa de romance que tienes también sale en «Romance». Una fila con menos de 4
  obras no se enseña.
- **Calidad máxima siempre** en el lector web: las páginas llegan en su tamaño original, sin reducir.
- **Primera visita**: la pantalla de carga espera hasta 15 s a que estén las portadas y mientras tanto enseña
  curiosidades de anime, manga y manhwa. Las siguientes veces entra rápido (portadas ya guardadas).
- App: búsqueda por **Obras** primero (cada obra una vez, se abre al instante) y portadas del servidor que ya cargan.

### Cómo actualizar
- **VPS:** `cd ~/yomukai && docker compose pull && docker compose up -d`
- **Worker:** `cd ~/yomukai-worker && docker compose -f docker-compose.worker.yml pull && docker compose -f docker-compose.worker.yml up -d`
- **Móvil:** `Yomukai-v2.8.0-arm64-v8a.apk` de esta página, instalada encima.
- **Navegador / PWA:** recarga una vez (Ctrl+Shift+R).
